# Repository-specific research skills

These reusable Markdown procedures are repository guidance, not newly generated Spec Kit workflows and not verified slash commands in Arena. The installed Spec Kit generic integration remains under `.agents/skills/speckit-*`.

- `wallex-source-research`: official-source provenance and honest coverage status.
- `wallex-contract-review`: version/host/schema discrepancy handling.
- `market-data-quality`: offline OHLCV checks without repair.
- `backtest-audit`: causal timing, costs, and realistic limits.
- `risk-review`: explicit caller-supplied Spot exposure bounds.
- `paper-replay`: local-only simulation, not exchange-connected paper trading.
- `security-review`: secrets, personal data, and side-effect review.
- `compliance-gate`: future jurisdiction-specific legal/compliance process; no legal advice.
- `smart98-interface-boundary`: preserve an unspecified integration seam without inventing a provider contract.

All are subordinate to `.specify/memory/constitution.md`, Feature 001/002 specifications, and `AGENTS.md`.
