# Account balances and fees

- The basic account-fee prose page documents `GET /v1/account/fee`; the fully reviewed generated page describes API-key-protected `GET https://api.wallex.com/v1/account/fee` and per-market `makerFeeRate`, `takerFeeRate`, `recent_days_sum`. It contains sample values, not a current account result or fee schedule. [ACCOUNT-FEE](https://developers.wallex.ir/docs/basic-services-account-fee) · [MOD-GENERATED-GET-ACCOUNT-FEES](https://developers.wallex.ir/docs/generated/get-account-fees)
- The generated balances page describes API-key-protected `GET https://api.wallex.com/v1/account/balances` and `value`/`locked` per asset. No account data was fetched. [MOD-GENERATED-GET-ACCOUNT-BALANCES](https://developers.wallex.ir/docs/generated/get-account-balances)
- The generated wallet-by-symbol page describes API-key-protected `GET https://api.wallex.com/v1/account/wallets/:symbol` plus optional `network`, and a response containing wallet address, network availability, confirmation, and min/fee fields. This is sensitive wallet/account information and was not accessed at runtime. [MOD-GENERATED-GET-ACCOUNT-WALLET-BY-SYMBOL](https://developers.wallex.ir/docs/generated/get-account-wallet-by-symbol)
- The developer overview says base host `api.wallex.ir`; these generated pages/specs show `api.wallex.com`. This material host disagreement is unresolved; no endpoint is selected or tested. [MOD-INTRO](https://developers.wallex.ir/docs) · [MOD-SPEC-BASIC-SERVICES](https://developers.wallex.ir/assets/files/basic-services-89626420b5f06e4d7a2dc9206cdeb192.json) · [D-013](../research/discrepancies.md)
- The official commission page's returned table had blank rate cells, while the promotional article is not known to be current. Do not use historical samples as today's cost assumptions. [WALLEX-COMMISSION](https://wallex.ir/commission) · [WALLEX-FEE-PROMO-ARTICLE](https://wallex.ir/blog/%DA%A9%D8%A7%D8%B1%D9%85%D8%B2%D8%AF-%D9%85%D8%B9%D8%A7%D9%85%D9%84%D8%A7%D8%AA-%D8%A7%D8%B3%D9%BE%D8%A7%D8%AA-%D8%AF%D8%B1-%D9%88%D8%A7%D9%84%DA%A9%D8%B3-%D8%A8%D9%87-%DB%B0%D9%AB%DB%B1%D9%AA-%D9%85/)

No account data, real key, wallet address, bank information, balance, or fee result is stored. Current rates, tier rules, permissions, and product-specific exceptions remain unresolved.
