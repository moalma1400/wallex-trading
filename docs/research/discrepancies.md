## Source-currentness note

مرجع `api-docs.wallex.ir` در مقدمه خودش را منطبق با آخرین تغییرات API معرفی می‌کند، اما صفحه شامل نمونه‌های timestampدار 2020 تا 2023 و routeهایی است که با مستند جدید فرق دارند. هیچ اطلاعیه رسمی صریحی مبنی بر خاموش شدن کل مرجع قدیمی در این بررسی دیده نشد؛ بنابراین `legacy` برچسب پژوهشی بر اساس سبک/نمونه‌ها و اختلاف است، نه ادعای رسمی deprecation کل سند. هر ادعای endpoint باید دوباره قبل از طراحی اجرا بررسی شود.
