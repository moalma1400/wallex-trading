# داده تاریخی بازار و کنترل کیفیت — Feature 003

Feature 003 فقط فایل CSV/JSON محلیِ ارائه‌شده توسط کاربر را import می‌کند. هیچ درخواست HTTP، اتصال WebSocket، کلید API، حساب خصوصی، سفارش یا انتقالی اجرا نمی‌شود. رابط provider صرفاً یک `Protocol` نوع‌دار برای توسعه احتمالی آینده است و پیاده‌سازی شبکه ندارد. [مشخصات](../../specs/003-historical-market-data/spec.md) · [قرارداد داده محلی](../../specs/003-historical-market-data/contracts/local-dataset.md) · [راهنمای اجرا](../../specs/003-historical-market-data/quickstart.md)

## گردش داده

- فایل اصلی بدون تغییر، با مسیر مبتنی بر SHA-256 نگه‌داری می‌شود؛ داده نرمال‌شده جداگانه و با نسخه schema، Decimal دقیق، زمان UTC آگاه از منطقه، منبع و hash ذخیره می‌شود.
- زمان بازیابی منبع و زمان ورود محلی باید صریح باشند. برای عمق بازارِ بدون زمان رویداد مستند، زمان capture جداست و جای زمان رویداد را نمی‌گیرد.
- JSON با کلید تکراری، زمان بدون timezone، عدد نامتناهی، ردیف نامعتبر، OHLC ناسازگار و ساختار ناشناخته رد می‌شوند. رکوردهای تکراری یا نامرتب حذف/مرتب نمی‌شوند؛ گزارش می‌شوند. قیمت‌ها در gap هرگز درون‌یابی نمی‌شوند.
- گزارش JSON، CSV و Markdown سیاست و نتیجه را نگه می‌دارد. بدون نمادهای مجاز، بازه/فاصله مورد انتظار، freshness و precision صریح، وضعیت «نامعلوم» است، نه تأیید.
- خروجی replay فقط برای کندلِ واجد شرایط صادر می‌شود و همان ستون‌های Feature 002 را دارد. فایل خروجیِ متفاوت بازنویسی نمی‌شود. Feature 002، زمان‌بندی تصمیم/اجرای کندل بعدی و مدل هزینه تغییر نکرده است.

## حدود شواهد والکس

صفحه‌های رسمی و نمونه‌های OpenAPI قراردادهای یکسانی نشان نمی‌دهند؛ میزبان، الزامی بودن پارامتر، یادداشت احراز هویت، انواع عددی و resolutionها اختلاف دارند. سقف عددی rate limit، pagination، بازه نگه‌داری، مرز زمانی و availability عملیاتی از شواهد بررسی‌شده تعیین نشده‌اند. feed `all@price` تغییرات را می‌فرستد و snapshot اولیه/تاریخچه ندارد؛ `all@fairPrice` snapshot قیمت منصفانه است و نباید با آخرین معامله یکی گرفته شود. snapshotهای depth در مستند WebSocket delta نیستند، ولی شروع اشتراک نیز snapshot اولیه نمی‌دهد. هیچ‌یک از این feedها در کد متصل نشده‌اند. [منابع بازار](../api/order-book-trades-candles.md) · [وب‌سوکت](websocket-and-market-data.md) · [دفتر منابع](../research/source-register.yaml)

داده ساختگیِ مخزن داده والکس واقعی نیست. گزارش موفق نیز اصالت منبع، کامل‌بودن بیرون از سیاست انتخابی، سودآوری یا ایمنی اجرای زنده را اثبات نمی‌کند. هزینه، ریسک و فرض‌های replay باید جداگانه و صریح بررسی شوند.
