# نمای کلی و جایگاه مستندات

والکس در صفحه اصلی خود بازارهای Spot، معامله آنی، اعتبار معاملاتی و «API پیشرفته» را معرفی می‌کند. صفحه اصلی همچنین به معامله تعهدی اشاره دارد. این متن بازاریابی فقط وجود معرفی محصول را نشان می‌دهد و مشخصات عملیاتی یا دسترسی یک حساب را اثبات نمی‌کند. [WALLEX-HOME](https://wallex.ir/)

مستند توسعه‌دهندگان جدید، API base را `https://api.wallex.ir` اعلام می‌کند و مقدمه‌ای درباره API عمومی/خصوصی دارد. مرجع قدیمی `api-docs.wallex.ir` ساختار ناوبری دیگری دارد. صفحه‌ها و دسته‌ها در [ماتریس پوشش](../research/coverage-matrix.md) فهرست شده‌اند. [MOD-INTRO](https://developers.wallex.ir/docs) · [LEGACY-API](https://api-docs.wallex.ir/)

این پژوهش فقط اسناد عمومی را می‌خواند: هیچ حساب یا endpoint تولیدی بررسی نشده و هیچ معامله یا تغییر حساب انجام نشده است. هر عدد یا قابلیت ممکن است تغییر کند و باید از صفحه رسمی جاری بررسی شود.
